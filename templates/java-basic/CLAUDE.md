
# Java Project - Claude Code Instructions

## Project Overview

This is a Java command-line application generated by
the Java Development Harness.

Technologies:
- Java 25
- Apache Maven
- JUnit 5
- Checkstyle
- Docker

## Project Structure

- s
  rc/main/java: application source code
- src/test/java: automated tests
- pom.xml: Maven configuration
- checkstyle.xml: code quality rules
- Dockerfile: containerized test environment
## Development Guidelines

- Read the existing code before making changes.
- Keep modifications focused on the requested task.
- Follow the existing Java code style.
- Write or update JUnit tests for new functionality.
- Do not remove tests just to make the build pass.
- Explain why new dependencies are needed.
- Do not introduce a database, GUI, or web framework
  unless explicitly requested.

## Validation

After modifying Java code, run:

    mvn clean test

This command includes Checkstyle validation
and JUnit tests.

When Docker validation is needed, run:

    docker build -t java-project-test .
    docker run --rm java-project-test

Report any errors or failed tests.
Never claim a validation passed if it was not executed.

## Safety and Version Control

- Do not access or expose credentials or secrets.
- Do not modify files outside the project without permission.
- Ask before executing destructive operations.
- Do not commit, push, or merge changes unless requested.
- Summarize the files changed and validation results.
